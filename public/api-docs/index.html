绵云图像接口

gpt-image-2 文生图 API

通过 OpenAI 兼容接口生成 1K 或 2K 图片。图片尺寸直接使用 size 参数传递，无需在模型名称后拼接任何后缀。

OpenAI 兼容 1K / 2K low / medium / high 服务可用
POST https://mianyunai.com/v1/images/generations
鉴权 请求头填写绵云 API 用户密钥：Authorization: Bearer YOUR_API_KEY。

快速开始

下面的请求会生成一张 1024 × 1024 图片。请将示例密钥替换为你的 API 用户令牌。

cURL
curl -X POST "https://mianyunai.com/v1/images/generations" \
  -H "Authorization: Bearer 你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只坐在窗边的橘猫，柔和自然光，真实摄影风格",
    "size": "1024x1024",
    "quality": "low",
    "n": 1
  }'
模型名称 model 固定填写 gpt-image-2，不要添加 -low、-2k 或 -4k 后缀。

请求参数

请求体使用 JSON。图片尺寸统一通过 size 字段传递，直接填写推荐的像素尺寸。

参数类型必填默认值说明
modelstring是-固定填写 gpt-image-2
promptstring是-图片生成提示词
sizestring否1024x1024直接传递推荐像素尺寸，例如 1024x1024 或 2048x1152
qualitystring否low支持 low、medium、high
ninteger否1生成数量，多张支持情况取决于上游
response_formatstring否上游决定常见值为 url 或 b64_json
userstring否-可选的终端用户标识

质量选项

low
medium
high

未传递质量时默认使用 low。

调用示例

以下示例生成一张 2K、16:9 的宽银幕图片，尺寸通过 size 直接传入。

cURL
curl -X POST "https://mianyunai.com/v1/images/generations" \
  -H "Authorization: Bearer 你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "宽银幕电影感的雪山日出，云海，金色阳光，细节丰富",
    "size": "2048x1152",
    "quality": "high",
    "n": 1
  }'
JavaScript
const response = await fetch(
  "https://mianyunai.com/v1/images/generations",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer 你的API密钥",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      model: "gpt-image-2",
      prompt: "宽银幕电影感的雪山日出，云海，金色阳光",
      size: "2048x1152",
      quality: "high",
      n: 1
    })
  }
);

const result = await response.json();
if (!response.ok) {
  throw new Error(result.error?.message || "图片生成失败");
}

console.log(result.data[0].url);
Python
import requests

url = "https://mianyunai.com/v1/images/generations"
headers = {
    "Authorization": "Bearer 你的API密钥",
    "Content-Type": "application/json",
}
payload = {
    "model": "gpt-image-2",
    "prompt": "宽银幕电影感的雪山日出，云海，金色阳光",
    "size": "2048x1152",
    "quality": "high",
    "n": 1,
}

response = requests.post(url, headers=headers, json=payload, timeout=600)
response.raise_for_status()
print(response.json()["data"][0]["url"])

响应格式

成功响应通常包含图片 URL。客户端应先检查 HTTP 状态，再读取 data[0].url。

JSON Response
{
  "created": 1784515242,
  "data": [
    {
      "url": "https://图片域名/generated/output.png"
    }
  ]
}

上游返回 Base64 数据时，图片字段可能为 b64_json。

错误处理

错误响应使用统一的 error 对象。建议记录 HTTP 状态码、错误码和 message。

参数错误响应
{
  "error": {
    "message": "Unsupported size for model gpt-image-2",
    "type": "invalid_request_error",
    "param": "size",
    "code": "invalid_parameter"
  }
}
HTTP 状态含义处理建议
400尺寸或质量参数无效检查 model、size 和 quality
401API 用户密钥无效检查 Authorization 请求头
404接口路径或模型配置错误确认使用 /v1/images/generations
429请求频率过高或额度不足降低并发或检查账户额度
500服务端或上游异常稍后重试并保留错误信息
502 / 504上游不可用或生成超时延长超时并检查反向代理

浏览器调用

前端应用建议通过自己的后端或同域路径转发请求，以避免跨域限制并保护 API 密钥。

JavaScript · 同源路径
const response = await fetch("/api/images/generations", {
  method: "POST",
  headers: {
    "Authorization": "Bearer 你的API密钥",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "gpt-image-2",
    prompt: "一座漂浮在云层之上的未来城市",
    size: "2048x2048",
    quality: "high"
  })
});
HTTPS 图片地址 HTTPS 网页不能安全读取 HTTP 图片。接口返回的图片 URL 也应使用 HTTPS，否则浏览器可能以 Mixed Content 为由拦截。
不要在公开网页内置固定密钥 写入前端 JavaScript 的密钥可以被访问者查看。正式业务应由自己的后端代为请求，或使用用户独立且受限的密钥。

使用须知

  • 客户端使用绵云 API 用户密钥，不要共享或公开密钥。
  • 请求模型名称必须准确填写为 gpt-image-2。
  • 所有图片尺寸通过 size 传递，不要把分辨率写入模型名称。
  • 推荐直接使用尺寸表中的像素值，例如 1024x1024、2048x1152。
  • 2K 生成可能需要较长时间，客户端和反向代理超时建议设置为至少 300 秒。
  • 返回图片可能具有有效期，重要结果应及时下载到自己的存储服务。
